隐私政策

这份政策说明 AgentCode（以下简称"本服务"）会收集你的哪些数据、用来做什么、 会给到谁、存多久，以及你可以怎么导出和删除它们。

本服务由 吴咏翰（个人）运营。有任何与数据相关的问题， 联系 824346648@qq.com。

二、我们收集什么

数据 具体是什么
账号 你设置的用户名、密码（只存不可逆的哈希，我们看不到明文）、套餐与用量记录
对话内容 你在页面上输入的任务描述，以及智能体给出的回答
文件 你主动上传的文件，以及智能体在执行任务过程中生成的文件与测试代码
运行记录 每次任务用了多少 token、调用了哪些工具、耗时多久（用于计费与排障）
登录态 一个签名的 Cookie。它只用来判断"你是谁"，不含任何个人信息，也不用于广告追踪
通知邮箱
（可选）		 你自己填的邮箱，只用来给你发服务通知：套餐到期、额度用尽、 账号被人多次猜密码、注销完成。留空就不收集、也不会收到通知； 它不会用于广告，也不会交给第三方。注销账号时会随账号一起删除
我们不使用第三方广告或分析脚本，页面上没有任何追踪像素。 上面这些就是全部。

三、这些数据会给到谁

接收方 拿到什么 为什么
大语言模型服务商 你的任务描述，以及智能体读到的文件内容（例如你上传的源码） 智能体要把这些内容发给模型才能干活。具体是哪家服务商取决于本实例的部署配置， 你可以向运营方询问；它们的处理规则适用各自的服务条款与隐私政策
服务器托管商 磁盘上的数据（托管方在物理层面能看到，但我们不会主动共享） 本服务跑在租用的服务器上
请不要上传你无权分享的内容——包括他人的隐私数据、商业机密、 以及你不希望被模型服务商处理的东西。发送给模型的内容，我们无法替你把关。

我们不会出售你的数据。

四、存多久

默认保留到你主动删除。我们不会因为"时间到了"就替你清掉—— 你的对话和文件什么时候该消失，由你决定。

如果本实例的运营方配置了自动清理（环境变量 AGENT_RETENTION_DAYS）， 那么超过该天数的会话与代码文件会被自动删除。你可以向运营方确认这项设置。

五、你可以做什么

权利 怎么做
导出 网页左下角「我的数据 → 导出」会把你的全部会话和代码目录打包成 zip 下载
删除单个会话 左侧会话列表上点 ✕
清空代码目录 「我的数据 → 清空代码目录」删除你上传的和智能体生成的全部文件
注销账号 「我的数据 → 注销账号」会删除你的账号、全部会话、全部代码与上传文件。 此操作不可撤销，所以需要输入用户名二次确认

也可以直接发邮件给上面的地址，我们会在合理期限内处理。

六、安全

密码以 PBKDF2-SHA256 加盐哈希保存，我们看不到明文。智能体执行代码时， 代码运行在隔离的容器里（无网络、只读根文件系统、以非 root 身份运行）。 但请理解：没有任何系统能保证绝对安全，请不要把本服务当作 存放高敏感数据的地方。

七、政策的变更

如果这份政策有实质性变化，我们会更新本页顶部的日期。继续使用本服务， 即表示你接受更新后的政策。
